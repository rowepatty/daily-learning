HTML & CSS — Try It Today

CSS gradients (linear-gradient)

CSS can paint smooth multi-color gradient backgrounds with one line of code - no image file needed. background: linear-gradient(45deg, red, blue) blends any colors you list, at any angle, and the browser draws it live.

<!DOCTYPE html>
<html><head><style>
  body {
    height: 100vh; margin: 0;
    background: linear-gradient(45deg, #ff9a9e, #fad0c4, #a1c4fd);
    display: flex; align-items: center; justify-content: center;
  }
  h1 {
    font-family: sans-serif; color: white; font-size: 3em;
    background: linear-gradient(90deg, purple, orange);
    padding: 20px 40px; border-radius: 15px;
  }
</style></head>
<body><h1>Gradient magic!</h1></body></html>

Why it’s cool: Gradients are how modern sites get that polished, colorful look without downloading a single image - they stay razor-sharp at any screen size, and changing one color or the angle instantly changes the whole mood of the page.
