HTML & CSS — Try It Today

CSS @keyframes animation (movement with zero JavaScript)

CSS can animate all by itself. With @keyframes you describe what an element looks like at the start, middle and end, give it a name, and hand that name to an element with the 'animation' property — the browser draws every in-between frame for you, roughly 60 times a second, and keeps looping forever if you tell it to. No JavaScript, no library, no timers. It is the difference between :hover (which needs you to point at something) and animation (which just goes).

Make a file animate.html, paste this in, open it in your browser — nothing to click:

<!doctype html>
<html><head><style>
  body { background: #10151f; height: 100vh; margin: 0;
         display: flex; align-items: center; justify-content: center; }

  @keyframes float {
    0%   { transform: translateY(0);      background: tomato; }
    50%  { transform: translateY(-80px);  background: gold; }
    100% { transform: translateY(0);      background: tomato; }
  }

  .ball {
    width: 90px; height: 90px;
    border-radius: 50%;
    animation: float 1.6s ease-in-out infinite;
  }
</style></head>
<body><div class="ball"></div></body></html>

Now play: change 1.6s to 0.4s (frantic) or 6s (dreamy). Swap 'infinite' for '3' so it stops after three bounces. Add a second colour stop at 25%. Add 'animation-delay: 0.5s'.

Why it’s cool: This is the first thing that makes a plain .html file feel alive instead of like a printed page — and you got there with about six lines of CSS. Once you can see @keyframes working, loading spinners, pulsing buttons and fade-ins all stop being mysteries.
