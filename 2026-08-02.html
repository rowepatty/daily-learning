HTML & CSS — Try It Today

The ::selection pseudo-element (restyle the highlight colour)

When you drag your mouse across text, the browser paints a highlight -- usually blue. That highlight is a thing you can style. The ::selection pseudo-element lets you set your own background and text colour for whatever the visitor has selected, in two lines of CSS and zero JavaScript. It's one of the very few ways plain CSS reacts to something the user is doing right now.

Save this as select.html, open it, then drag your mouse across the paragraph:

<!doctype html>
<html><head><style>
  body {
    font-family: Georgia, serif;
    max-width: 34em;
    margin: 60px auto;
    line-height: 1.7;
  }

  /* the whole page's highlight colour */
  ::selection {
    background: #ffd166;   /* highlighter yellow */
    color: #1a1a1a;
  }

  /* one element can override it */
  .spooky::selection {
    background: #2b2d42;
    color: #ff006e;
  }
</style></head>
<body>
  <h1>Highlight me</h1>
  <p>Drag your mouse across this sentence and you'll get a
     yellow highlighter instead of the usual blue.</p>
  <p class="spooky">Now drag across THIS sentence. Different
     element, different rules.</p>
</body></html>

Try swapping #ffd166 for 'limegreen', or set background to 'transparent' and watch the highlight vanish while the text stays selectable.

Why it’s cool: It's a tiny detail that makes a page feel hand-made -- and it's a first taste of a big CSS idea: pseudo-elements let you style parts of the page that aren't real HTML tags you wrote.
