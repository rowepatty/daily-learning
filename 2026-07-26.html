HTML & CSS — Try It Today

The <details> & <summary> elements (built-in dropdown)

HTML has a native click-to-expand accordion: wrap content in <details>, give it a <summary> as the clickable title, and the browser handles opening and closing with zero JavaScript. You can even style it differently while open using the details[open] CSS selector.

<!DOCTYPE html>
<html>
<head>
<style>
  details { border: 2px solid #7c3aed; border-radius: 8px;
            padding: 10px; max-width: 400px; font-family: sans-serif; }
  summary { cursor: pointer; font-weight: bold; color: #7c3aed; }
  details[open] { background: #f5f3ff; }
</style>
</head>
<body>
  <details>
    <summary>Click me - no JavaScript here!</summary>
    <p>This dropdown opens and closes all by itself.
       The browser does all the work.</p>
  </details>
</body>
</html>

Why it’s cool: Interactive dropdowns are something most people assume need JavaScript - but this is 100% HTML/CSS. It's how many FAQ sections on real websites are built.
