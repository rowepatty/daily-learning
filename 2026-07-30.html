HTML & CSS — Try It Today

CSS Grid auto-fit (a layout that rearranges itself)

One line of CSS Grid can build a responsive card layout that reflows on its own: 'grid-template-columns: repeat(auto-fit, minmax(180px, 1fr))'. It tells the browser "fit as many columns as you can, each at least 180px wide, and share the leftover space equally." Widen the window and you get more columns; narrow it and the cards stack — with no media queries and no JavaScript.

Save as grid.html and open it, then drag the window narrower and wider:

<!doctype html>
<html><head><style>
  body { font-family: sans-serif; background: #f4f6f8; padding: 20px; }
  .cards {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
    gap: 16px;
  }
  .card {
    background: white;
    border-radius: 10px;
    padding: 20px;
    box-shadow: 0 2px 6px rgba(0,0,0,.12);
    text-align: center;
  }
</style></head>
<body>
  <h1>Drag the window edge</h1>
  <div class="cards">
    <div class="card">One</div>
    <div class="card">Two</div>
    <div class="card">Three</div>
    <div class="card">Four</div>
    <div class="card">Five</div>
    <div class="card">Six</div>
  </div>
</body></html>

Try changing 180px to 300px and watch the number of columns drop.

Why it’s cool: It is the closest CSS gets to magic: the browser does the math for you, so one rule replaces the pile of breakpoints people used to hand-write. Resizing the window and watching the cards rearrange themselves is genuinely fun the first time.
