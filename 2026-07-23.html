HTML & CSS — Try It Today

CSS named colors

CSS ships with ~148 built-in color names you can type instead of hex codes — and some are delightfully weird: 'papayawhip', 'gainsboro', 'lightgoldenrodyellow', and 'rebeccapurple' (added to honor web pioneer Eric Meyer's daughter Rebecca).

Make a file try.html, paste this, open it in your browser:

<!doctype html>
<html><head><style>
  body { background: papayawhip; }
  h1 { color: rebeccapurple; }
</style></head>
<body><h1>Hello, color!</h1></body></html>

Then swap 'papayawhip' for 'gainsboro' or 'mistyrose' and refresh.

Why it’s cool: You can style a whole page with plain English words — no hex, no tools. It makes CSS feel approachable, and teaches you that the browser has a built-in color dictionary.
