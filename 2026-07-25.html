HTML & CSS — Try It Today

:hover + transition (pure-CSS interactivity)

CSS elements can react to your mouse with the :hover pseudo-class - and adding one 'transition' line makes the change animate smoothly instead of snapping. People assume you need JavaScript for interactive buttons; you don't.

Save as hover.html and open it:

<!doctype html>
<html><head><style>
  .btn {
    display: inline-block;
    padding: 16px 32px;
    font-family: sans-serif;
    font-size: 20px;
    color: white;
    background: tomato;
    border-radius: 10px;
    transition: all 0.3s ease;
  }
  .btn:hover {
    background: rebeccapurple;
    transform: scale(1.15) rotate(-2deg);
    box-shadow: 0 10px 20px rgba(0,0,0,0.3);
  }
</style></head>
<body>
  <div class="btn">Hover over me!</div>
</body></html>

Try changing 0.3s to 2s, or rotate(-2deg) to rotate(360deg), and refresh.

Why it’s cool: One selector and one transition line give you a living, animated button with zero JavaScript - it's the moment a page stops feeling like a document and starts feeling like an app.
