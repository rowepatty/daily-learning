HTML & CSS — Try It Today

CSS custom properties (variables)

CSS lets you invent your own reusable values. Any name starting with two dashes - like --main: #6c3fc7 - declared inside :root becomes a variable you can reuse anywhere with var(--main). Change that one declaration and every place that used it updates instantly.

Save as theme.html and open it:

<!doctype html>
<html>
<head>
<style>
  :root {
    --main: #6c3fc7;
    --soft: #f2ecff;
    --radius: 14px;
  }
  body {
    font-family: system-ui, sans-serif;
    background: var(--soft);
    padding: 40px;
  }
  .card {
    background: white;
    border: 3px solid var(--main);
    border-radius: var(--radius);
    padding: 20px;
    margin-bottom: 16px;
  }
  h1 { color: var(--main); }
  .btn {
    display: inline-block;
    background: var(--main);
    color: white;
    padding: 10px 18px;
    border-radius: var(--radius);
  }
</style>
</head>
<body>
  <h1>One variable rules them all</h1>
  <div class="card">This card's border uses var(--main).</div>
  <div class="card">So does the heading, and the button below.</div>
  <span class="btn">A button</span>
</body>
</html>

Now change ONLY this one line near the top:
    --main: #6c3fc7;
to
    --main: #0f8f6f;
Save, refresh the browser. The heading, both card borders and the button all change colour at once.

Why it’s cool: It turns your stylesheet into a control panel: one line becomes the theme switch for the whole page, and you never have to hunt down the same hex code in fifteen different rules again.
