HTML & CSS — Try It Today

The ::first-letter pseudo-element (drop caps)

CSS can style the very first letter of a paragraph all by itself - no extra HTML, no <span> wrapped around the letter. The selector p::first-letter reaches into the text and grabs that one character, so you can make it huge and let the rest of the paragraph wrap around it, exactly like the decorated opening letters in a magazine or an old storybook. There's a matching ::first-line that styles the whole first line, and the browser recalculates which characters count as 'the first line' every time you resize the window.

Save this as dropcap.html and open it in your browser:

<!doctype html>
<html><head><style>
  body {
    font-family: Georgia, serif;
    max-width: 40em;
    margin: 40px auto;
    line-height: 1.6;
  }
  p::first-letter {
    float: left;            /* let the text wrap around it */
    font-size: 4.5em;       /* 4.5x the normal text size  */
    line-height: 0.8;
    padding-right: 8px;
    color: #8b2e2e;
    font-weight: bold;
  }
  p::first-line {
    font-variant: small-caps;   /* bonus: styles the whole first line */
  }
</style></head>
<body>
  <p>Once upon a time there was a paragraph that wanted to look like it belonged in a very old, very expensive book. It did not need any extra HTML to get its wish - just two lines of CSS and a browser willing to play along.</p>
</body></html>

Now make the browser window narrower and wider. Watch the small-caps first line change length as the text re-wraps, while the big red letter stays put.

Why it’s cool: You get a genuinely fancy, hand-lettered look from two lines of CSS and zero extra markup - and it's your first taste of pseudo-elements, the CSS trick of styling parts of the page that don't have their own tag.
