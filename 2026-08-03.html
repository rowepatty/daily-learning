HTML & CSS — Try It Today

The :target pseudo-class (clickable tabs with zero JavaScript)

When you click a link like <a href="#two">, the browser adds #two to the address bar and the element whose id is "two" becomes the page's :target. CSS can style that element differently from every other element — so you can hide three panels, and reveal only the one whose link was just clicked. That is real click-driven interactivity built entirely out of a link, an id, and one CSS rule.

Make a file try.html, paste this, open it in your browser, then click the three links:

<!doctype html>
<html><head><style>
  body { font-family: system-ui; padding: 2rem; }
  a { margin-right: 1rem; }
  .card {
    display: none;
    margin-top: 1rem;
    padding: 1rem;
    border: 2px solid rebeccapurple;
    background: lavender;
  }
  .card:target { display: block; }
</style></head>
<body>
  <h1>Pure-CSS tabs</h1>
  <a href="#one">Show One</a>
  <a href="#two">Show Two</a>
  <a href="#three">Show Three</a>

  <div class="card" id="one">I am panel ONE.</div>
  <div class="card" id="two">I am panel TWO.</div>
  <div class="card" id="three">I am panel THREE.</div>
</body></html>

Bonus: press the browser's Back button — the panels step backwards, because each click was a real URL change.

Why it’s cool: It feels like you cheated. Tabs are the classic 'you'll need JavaScript for this' feature, and here they're one selector. It also teaches you that the # part of a URL is something CSS can see and react to.
