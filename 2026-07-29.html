HTML & CSS — Try It Today

position: sticky (headings that stick as you scroll)

Add two lines of CSS - 'position: sticky' and 'top: 0' - and an element will scroll along normally until it reaches the top of the screen, then freeze there while the rest of the page keeps moving past it. It is the effect behind almost every app's floating header and every spreadsheet's frozen row, and for years it needed JavaScript. Now the browser does it for free, and it even knows to un-stick when its parent section scrolls out of view.

Save as sticky.html and open it, then scroll slowly:

<!doctype html>
<html><head><style>
  body { font-family: sans-serif; margin: 0; }
  h2 {
    position: sticky;   /* the magic */
    top: 0;             /* stick to the very top */
    margin: 0;
    padding: 12px 16px;
    background: #2193b0;
    color: white;
  }
  p { padding: 16px; line-height: 1.6; }
</style></head>
<body>

  <section>
    <h2>Chapter 1</h2>
    <p>Scroll down slowly and watch this heading stick to the top.</p>
    <p>Keep scrolling...</p>
    <p>Still Chapter 1...</p>
    <p>Almost there...</p>
  </section>

  <section>
    <h2>Chapter 2</h2>
    <p>Chapter 1's heading got pushed away and this one took over.</p>
    <p>More text...</p>
    <p>And more...</p>
    <p>The end.</p>
  </section>

</body></html>

Try changing 'top: 0' to 'top: 40px' to make it stop 40 pixels down instead.

Why it’s cool: It is a genuinely fancy app-like effect from two lines of CSS and zero JavaScript, and the way each heading politely shoves the previous one off screen is something the browser handles entirely on its own.
