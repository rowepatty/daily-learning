HTML & CSS — Try It Today

clip-path (cutting shapes out of plain boxes)

Every element in HTML is a rectangle - but the CSS property clip-path lets you cut that rectangle into any shape you like using a list of x/y percentage points. One line turns a square div into a hexagon, a triangle, or a ten-pointed star, with no images and no JavaScript.

Save this as shapes.html and open it in your browser:

<!doctype html>
<html><head><style>
  body { background: #111; display: flex; gap: 24px; padding: 40px; }
  .shape {
    width: 150px; height: 150px;
    background: linear-gradient(45deg, #ff6b6b, #feca57);
  }
  .hexagon  { clip-path: polygon(25% 0%, 75% 0%, 100% 50%, 75% 100%, 25% 100%, 0% 50%); }
  .triangle { clip-path: polygon(50% 0%, 100% 100%, 0% 100%); }
  .star     { clip-path: polygon(50% 0%, 61% 35%, 98% 35%, 68% 57%, 79% 91%,
                                 50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35%); }
</style></head>
<body>
  <div class="shape hexagon"></div>
  <div class="shape triangle"></div>
  <div class="shape star"></div>
</body></html>

Every div is still a plain square - clip-path just hides the parts outside the shape. Try changing the percentages and refresh to invent your own shape.

Why it’s cool: It breaks the biggest mental rule beginners learn ('everything on a web page is a box') using a single property, and the percentage coordinates make it feel like drawing on graph paper.
